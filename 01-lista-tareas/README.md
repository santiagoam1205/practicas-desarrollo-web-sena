Lista de Tareas con Progreso

-Objetivo
Desarrollar una aplicación web responsiva de lista de tareas que permita agregar
tareas, marcarlas como completadas y visualizar el progreso de tareas realizadas.

-Requisitos Funcionales
La aplicación debe permitir al usuario:
Agregar tareas
Marcar tareas como completadas
Eliminar tareas
Visualizar el progreso de tareas completadas
